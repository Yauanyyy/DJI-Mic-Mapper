DJI Mic Mapper is a lightweight Windows utility that lets you use the button on a DJI Mic Mini receiver as a configurable keyboard key or shortcut.

The application runs in the system tray, so no window needs to stay open. It identifies the receiver through Windows Raw Input and can optionally handle the `Volume Up` input generated by the same device.

## Features

- Map the DJI Mic Mini button to a single key or a key combination.
- Use F1–F24, letters, numbers, navigation keys, modifier keys, punctuation keys, and common media keys.
- Choose how to handle `Volume Up` with `off`, `best_effort`, or `block_all`.
- Check the current mapping and runtime status from the tray menu.
- Reload configuration changes without restarting the application.
- Use an observation-only diagnostic mode when troubleshooting device detection or event timing.

## Download and run

Download the latest version from the [Releases](https://github.com/Yauanyyy/DJI-Mic-Mapper/releases) page:

- `DJI-Mic-Mapper-<version>-windows-x64-setup.exe`: Recommended. Run the installer and use the Start Menu shortcut to launch the application.
- `DJI-Mic-Mapper-<version>-windows-x64-portable.zip`: Portable version. Extract the archive and run the application directly.

### First launch

1. Install the setup version, or extract the portable version to a folder you can access.
2. Start `dji-mic-mapper.exe`. The application will continue running in the system tray.
3. Right-click the tray icon to view the current mapping, configuration path, and runtime status.
4. To change the mapping, edit `config.toml` next to the application and choose **Reload config** from the tray menu.

Windows may show a UAC prompt when the application starts. The current version requests administrator privileges so the global keyboard hook and input injection work with applications running at different privilege levels.

## Configuration

The configuration file is `config.toml` in the application directory. Create or edit it with a text editor, save your changes, and select **Reload config** from the tray menu. Restarting the application is not required.

Most users only need `target` and `volume_up_mode`. The repository includes a ready-to-edit [sample configuration](config.toml). Its main user-facing settings look like this:

~~~toml
target = "Ctrl+Shift+Home"
volume_up_mode = "best_effort"
log_level = "error"
correlation_window_ms = 10
~~~

Configuration options:

| Setting | What it controls | Default |
| --- | --- | --- |
| `target` | Key or shortcut sent when the DJI button is pressed | `F13` |
| `volume_up_mode` | How the receiver's `Volume Up` input is handled | `best_effort` |
| `suppress_volume_up` | Legacy compatibility option; use `volume_up_mode` instead | Not set |
| `log_level` | Logging level: `off`, `error`, `warn`, `info`, `debug`, or `trace` | `info` |
| `correlation_window_ms` | Time window used by `best_effort`, from 5 to 100 ms | `10` |
| `usage_page` | HID top-level collection Usage Page; normally only needed for advanced matching | `0x000C` |
| `usage` | HID top-level collection Usage; normally only needed for advanced matching | `0x0001` |
| `button_usage` | DJI button Usage; normally only needed for advanced matching | `0x00E9` |
| `report_id` | HID Report ID; `0` disables the preselected Report ID | `6` |

### Choose a target key

`target` accepts a single key or a shortcut. Use `+` between modifier keys and the key they modify:

~~~toml
target = "F13"
~~~

~~~toml
target = "Ctrl+Alt+]"
~~~

Key names are case-insensitive. Spaces, hyphens, and underscores are ignored, so `Volume_Up`, `Volume-Up`, and `volumeup` are equivalent.

| Category | Available names | Example or notes |
| --- | --- | --- |
| Letters | `A`–`Z` | `A`, `M`, `Z` |
| Numbers | `0`–`9` | Main keyboard number keys |
| Function keys | `F1`–`F24` | `F13` |
| Modifier keys | `Ctrl` (`Control`), `Alt`, `Shift`, `Win` (`Windows`, `Meta`), `LeftWin` (`LWin`), `RightWin` (`RWin`), `LeftAlt` (`LAlt`), `RightAlt` (`RAlt`, `AltGr`), `LeftShift` (`LShift`), `RightShift` (`RShift`) | Use as shortcut prefixes, for example `Ctrl+Shift+F13`; modifier keys can also be used on their own |
| Editing and control | `Backspace` (`Back`), `Tab`, `Enter` (`Return`), `Esc` (`Escape`), `Space` | `Ctrl+Alt+Delete` |
| Navigation | `PageUp` (`PgUp`), `PageDown` (`PgDn`), `Home`, `End`, `Insert` (`Ins`), `Delete` (`Del`), `Left`, `Up`, `Right`, `Down` | `Shift+Home` |
| Numeric keypad | `Numpad0`–`Numpad9`, `Multiply`, `Add`, `Subtract`, `Decimal`, `Divide`, `NumLock`, `ScrollLock` | `Numpad1`, `Add` |
| Media keys | `VolumeMute` (`Mute`), `VolumeDown`, `VolumeUp`, `NextTrack`, `PrevTrack` (`PreviousTrack`), `StopMedia` (`MediaStop`), `PlayPause` (`MediaPlayPause`) | `PlayPause` |
| OEM punctuation | `OEM1` (`Semicolon`, `;`), `OEM_PLUS` (`Equal`, `Equals`, `Plus`, `=`), `OEMComma` (`Comma`, `,`), `OEMMinus` (`Minus`, `Hyphen`, `-`), `OEMPeriod` (`Period`, `Dot`, `.`), `OEM2` (`Slash`, `ForwardSlash`, `/`), `OEM3` (`Backtick`, `Grave`, <code>`</code>), `OEM4` (`LeftBracket`, `LBracket`, `[`), `OEM5` (`Backslash`, `\\`), `OEM6` (`RightBracket`, `RBracket`, `]`), `OEM7` (`Apostrophe`, `Quote`, `'`) | For example, `Ctrl+Alt+OEM6`; `Shift+OEM6` means `}`, and `Shift+OEM_PLUS` means `+` |

`+` separates shortcut parts, so it cannot be used directly as `target = "+"`. To map the plus key, use `PLUS`, `Equal`, or `OEM_PLUS`. Backslashes and quotation marks in TOML strings must follow TOML escaping rules.

## Volume Up behavior

The receiver can generate a standard `Volume Up` event as well as its Raw Input button event. Choose the mode that best fits your setup:

### `off`

Do not intercept `Volume Up`. The volume increase generated by the DJI button remains active.

### `best_effort` (default)

Temporarily hold standard `Volume Up` events and compare them with DJI Raw Input events:

- Events identified as coming from the DJI receiver are discarded.
- Events whose source cannot be confirmed are replayed after the short correlation window.

This is the recommended mode for most users. It is a user-mode solution and cannot guarantee device-level suppression for every device or event timing.

### `block_all`

Suppress every `Volume Up` event recognized by Windows, including events from keyboards, headsets, microphones, and other devices. Use this mode only if you intentionally want to block volume increases from all sources; a warning is shown when it is enabled.

Volume down and mute are not affected.

## Diagnostics

Use diagnostic mode when the receiver is not detected or you need to inspect event timing:

~~~powershell
.\dji-mic-mapper.exe --diagnose
~~~

Diagnostic mode only observes events. It does not send the mapped key and does not suppress or replay `Volume Up`. Raw Input and Volume Up hook events are recorded so you can verify device detection and the timing relationship between the two event streams.

Logs are stored in the `logs` folder next to the application. For more detailed logs, set this option in `config.toml` and reload the configuration:

~~~toml
log_level = "trace"
~~~

## Advanced device matching

The default configuration matches the following DJI Mic Mini receiver parameters:

| Parameter | Default |
| --- | --- |
| VID | `0x2CA3` |
| PID | `0x4011` |
| Usage Page | `0x000C` |
| Usage | `0x0001` |
| Button Usage | `0x00E9` |
| Report ID | `6` |

Most users should leave these values unchanged. Usage and Report ID can be overridden in `config.toml` when troubleshooting a different HID interface. VID/PID are fixed to the default device to avoid accidentally matching other HID devices.

## Limitations

- The application supports Windows only.
- Raw Input is a listening interface; it cannot prevent Windows from consuming HID reports on a per-device basis.
- `best_effort` cannot provide absolute device-level suppression. That requires an HID filter driver.
- `block_all` affects every standard `Volume Up` input, not only the DJI receiver.
